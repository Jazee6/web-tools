# 执行用户提供的正则的 Tool 不开放远程 MCP

Regex Tester 把访客写的正则直接交给 JavaScript 引擎执行。带嵌套量词的病态正则（例如 `(a+)+$` 对一长串 `a`）会让回溯呈指数增长，无法中断。

在访客自己的浏览器里，最坏的结果是卡住当前标签页，访客可以关掉它，所以网页和页面内 WebMCP 照常开放；文本上限 100,000 字符，表格只列前 200 条匹配，把正常使用的耗时压在可接受范围内。

远程 MCP 在 Worker 里执行，匿名调用没有 Turnstile，一条病态正则就会耗尽 Free 计划的 CPU 时间并被限额拦截，影响其他访客。所以 `agent.remote: false`。换成浏览器里的 Web Worker 也不能解决问题：取消只是发一条消息，同步执行的正则收不到它，要终止就得丢弃整个 Worker。以后如果要给这类 Tool 开放远程 MCP，先要有可强制终止的执行环境（例如带超时的独立沙箱），或者换成线性时间的正则引擎。
