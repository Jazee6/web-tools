# Variant 可以收窄来源格式，差异按"预设 + 来源格式"判定

ADR-0005 要求 Variant 的预设不同于 Tool 的默认值、也不同于兄弟 Variant。但预设只能填表单里的选项，限定不了输入文件是什么格式。格式转换类 Tool 最主要的长尾搜索是"A 转 B"，比如 Video Converter 默认输出 MP4，"MOV 转 MP4"和"MKV 转 MP4"的预设都是"输出 MP4"：既等于默认值，彼此也相同，按原规则一个都做不出来。2026-10-23 改成：

- `variant.ts` 可以声明 `accept`：把某个文件字段收窄到 Tool 在 `fileType()` 里声明的部分 MIME 类型，例如 `{ file: ["video/quicktime"] }`。收窄必须是真子集，类型必须在 Tool 的类型表里。
- **只作提示，不改校验**：Variant 页的文件选择器只列出收窄后的类型（MIME 类型和扩展名），但表单校验仍接受 Tool 支持的全部类型。用户在"MOV 转 MP4"页拖进一个 MKV，照样能转换。
- **差异判定**：把"预设覆盖默认值后的全部非文件字段 + 收窄后的类型"作为 Variant 的配置，它必须不同于 Tool 的默认配置（全部默认值、不收窄），也不同于同一 Tool 下的其他 Variant。

其余门槛不变：独有数据非空、有搜索需求依据、有 en 内容、与兄弟页面（含 Tool 页）的近似度低于阈值。

## Considered Options

- 严格校验：Variant 页只接受收窄后的格式。语义更干净，但拖错文件的用户会被拒绝，而 Tool 本来就能处理那个文件。
- 不收窄，只用独有数据描述来源格式：差异判定仍然只看预设，"MOV 转 MP4"和"MKV 转 MP4"依旧无法共存。
