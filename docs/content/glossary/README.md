# 各 Locale 术语表

每个 Locale 一份：`en.md`（源语言，规定写法与禁用词）、`zh.md`、`ja.md`、`es.md`、`pt.md`、`de.md`、`fr.md`。`translate-content` 和审核都以它们为准，规则见 [风格指南](../style-guide.md)。

- 表中"译法"是**固定写法**，同一概念全站只用这一种；"避免"列出已被淘汰的说法。
- 已发布内容里的现有译法是本表的来源，改动译法要同步改全部已有内容并重新审核。
- 新增 Tool 时，先把 Tool 名、新概念加进 7 份术语表（en 先行），再写内容。
- 文件格式、编码、协议名（MP4、H.264、HTTP、JSON、PDF……）和库名（Mediabunny、PDFium……）保持原写法，不入表。
- UI 文案（`messages/{locale}.json`）与内容共用同一套译法；两者不一致时，以已上线的 UI 文案为准并修正本表。

## 表格式

每份术语表包含三块：**语气**（人称、敬语、标点）、**站点概念与界面词**、**Tool 与 Category 名称**。
