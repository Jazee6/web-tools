# ja 術語表

## 語気

- です・ます体。読者への呼びかけは省略し、「あなた」は使わない。
- 句読点は「、」「。」。英数字と日本語の間に半角スペースを入れる（`JSON を貼り付け`）。かっこは「」。
- ボタン名は「…」で囲み、`action` / `label` と完全に一致させる。
- カタカナ語は長音を付ける（フォーマッター、コンバーター、プライバシー）。
