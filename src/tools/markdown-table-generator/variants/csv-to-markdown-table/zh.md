## 按 RFC 4180 的定义读取 CSV

CSV 看起来简单，直到某个值里出现逗号、引号或换行。转换器遵循 [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180)，也就是大多数程序写出的格式：字段之间用逗号分隔，用双引号括起来的字段可以包含逗号和换行，加引号字段里的引号要写两次。行尾可以是 CRLF、LF 或 CR，所以 Windows、macOS 和 Linux 上的文件都能用。

## 选项与限制

- **CSV 大小：** 最多 200,000 个字符。
- **表头：** CSV 的第一行作为表头行；关闭"第一行是表头"后，改为加一行空表头。
- **参差不齐的文件：** 字段比最长一行少的行会在末尾补上空单元格，空行会被跳过。
- **分隔符：** 只认逗号。这个预设不会拆分用分号或制表符分隔的文件。
- **未闭合的引号：** 缺少结尾引号的字段会一直延续到文件末尾；如果最后一个单元格吞掉了好几行，请检查源文件。
- **不支持：** 从单独的文件读取表头、跳过某些列，以及转回 CSV。

处理只在你的设备上完成。页面不会上传、保存你的 CSV，也不使用 Cookie。
