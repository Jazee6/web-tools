## RFC 4180 の定義どおりに CSV を読む

CSV は単純に見えますが、値にカンマ、引用符、改行が入ると話が変わります。このツールは、ほとんどのプログラムが書き出す形式である [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180) に従います。フィールドはカンマで区切り、ダブルクォートで囲んだフィールドにはカンマや改行を含められ、引用符付きフィールド内の引用符は 2 つ重ねて書きます。行末は CRLF、LF、CR のどれでもよいため、Windows、macOS、Linux のファイルをそのまま使えます。

## オプションと制限

- **CSV のサイズ：** 最大 200,000 文字。
- **ヘッダー：** CSV の 1 行目がヘッダー行になります。「1 行目をヘッダー行にする」をオフにすると、代わりに空のヘッダー行を追加します。
- **列数がそろわないファイル：** 最も長い行よりフィールドが少ない行は末尾に空のセルを補い、空行は読み飛ばします。
- **区切り文字：** カンマだけです。このプリセットはセミコロン区切りやタブ区切りのファイルを分割しません。
- **閉じていない引用符：** 閉じ引用符がないフィールドはファイルの最後まで続きます。最後のセルに複数行が入ってしまう場合は、元のファイルを確認してください。
- **非対応：** 別ファイルからのヘッダーの読み込み、列の除外、CSV への逆変換。

## プライバシー

処理はお使いのデバイス上でのみ行われます。ページは CSV をアップロードも保存もせず、Cookie も使いません。
