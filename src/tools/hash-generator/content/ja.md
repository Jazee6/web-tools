faq:
  - q: テキストはサーバーにアップロードされますか？
    a: いいえ。ハッシュ値はすべてブラウザ内で計算され、テキストがデバイスの外に出ることはありません。ページの読み込みが終われば、オフラインでも使えます。
  - q: どのアルゴリズムを選べばよいですか？
    a: 他に指定がなければ SHA-256 を使ってください。SHA-384 と SHA-512 は同じ系列でより長いハッシュ値を出します。MD5 と SHA-1 は、攻撃者が衝突を作れるため、セキュリティ目的では破られています。チェックサムや古いシステムとの互換性のためだけに使ってください。
  - q: パスワードのハッシュ化に使えますか？
    a: いいえ。これらは高速な汎用ハッシュで、高速なハッシュは総当たりで簡単に破られます。パスワードを保存するときは、サーバー側で Argon2、scrypt、bcrypt のような低速でソルト付きのパスワードハッシュ関数を使ってください。
  - q: 他のツールと結果が違うのはなぜですか？
    a: テキストは入力したとおりの UTF-8 バイト列としてハッシュ化されるため、末尾の改行、余分なスペース、改行コードの違いで結果が変わります。他のツールが別の文字コードでテキストを読んでいる可能性もあります。
  - q: ファイルのハッシュも計算できますか？
    a: このツールでは計算できません。対象はテキストのみです。

## このハッシュツールでできること

テキストを UTF-8 のバイト列に変換し、そのバイト列のハッシュ値を計算します。SHA-1、SHA-256、SHA-384、SHA-512 は、[FIPS 180-4](https://csrc.nist.gov/pubs/fips/180-4/upd1/final) を実装したブラウザ組み込みの Web Crypto API を使います。MD5 は Web Crypto に含まれないため、ページ内に [RFC 1321](https://www.rfc-editor.org/rfc/rfc1321) に基づく独自実装を持ち、公式のテストベクターで検証しています。

## オプションと制限

- **アルゴリズム**：MD5、SHA-1、SHA-256、SHA-384、SHA-512。
- **出力形式**：小文字の 16 進数、大文字の 16 進数、Base64。
- **テキストのみ**：ファイルには非対応です。テキストはスペースや改行を含め、入力したとおりに計算されます。
- **パスワード用途には不向き**：これらのハッシュは設計上高速で、ソルトも付かないため、パスワードの保存には向きません。
- **サイズ**：デバイスのメモリだけが上限です。

## プライバシー

処理はお使いのデバイス上でのみ行われます。ページはテキストをアップロードも保存もせず、Cookie も使いません。
