## 转换原理

本工具用开源媒体库 Mediabunny 读取视频，再用浏览器内置的 WebCodecs API 解码和编码音视频流，通常还能用上硬件加速。目标格式本来就能装下的流会直接复制，不重新编码。处理在后台线程中进行，页面不会卡顿。

## 限制

- **输入：** MP4、MOV、WebM 和 MKV 文件，不超过 500 MB。
- **轨道：**只转换主视频轨和主音频轨，字幕和额外的音轨会被丢弃。
- **编码格式：**能解码和编码哪些格式取决于你的浏览器和设备。例如 Firefox 没有 AAC 编码器，因此在 Firefox 中 MP4 和 MOV 会使用 Opus 音频；最新版 Chrome 支持的编码格式最多。如果某条轨道无法转换，工具会停止并给出提示，而不会生成没有声音或画面的文件。
- **内存：**转换后的视频在下载前保存在内存中，在手机上转换很大的文件可能失败。

## 隐私

你的视频只在你的设备上处理。页面不会上传或保存视频，也不使用 Cookie。
