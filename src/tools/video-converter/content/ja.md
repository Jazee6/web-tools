steps:

  - 出力形式を選びます。MP4 はほぼどこでも再生でき、WebM はウェブ向け、MOV は Apple のアプリ向け、MKV は元のストリームをそのまま残します。

faq:
  - q: 動画はサーバーにアップロードされますか？
    a: いいえ。動画はブラウザ内で WebCodecs API を使って読み込み、デコード、エンコードされるため、デバイスの外に出ることはありません。
  - q: 変換が一瞬で終わることがあるのはなぜですか？
    a: 映像と音声のコーデックが新しい形式にそのまま入る場合（たとえば MOV から MP4 への H.264 と AAC）は、ストリームをそのままコピーしてコンテナだけを書き直します。再エンコードしないので速く、画質も変わりません。
  - q: 変換すると画質は落ちますか？
    a: 再エンコードが必要な場合だけです（たとえば WebM から MP4）。高画質の設定でエンコードするので違いはほとんど分かりませんが、再エンコードは完全に無劣化にはなりません。
  - q: 出力にはどのコーデックが使われますか？
    a: ブラウザが対応していれば、MP4 と MOV は H.264 の映像と AAC の音声を使います。対応していない場合（たとえば Firefox には AAC エンコーダーがありません）は、Opus 音声など、その形式が扱える別のコーデックを使います。WebM は VP9 と Opus、MKV は元のコーデックのままです。
  - q: MKV ファイルは変換できますか？
    a: 今のところできません。MKV は出力形式として選べますが、入力として MKV ファイルを選ぶことはまだできません。

## 変換のしくみ

このツールはオープンソースのメディアライブラリ Mediabunny で動画を読み込み、ブラウザに組み込まれた WebCodecs API でストリームをデコード・エンコードします。多くの場合ハードウェアアクセラレーションも使われます。出力形式にそのまま入るストリームは再エンコードせずにコピーします。処理はバックグラウンドのスレッドで行われるため、ページの操作は止まりません。

## 制限

- **入力：** 500 MB までの MP4、MOV、WebM ファイル。
- **トラック：** メインの映像トラックとメインの音声トラックを変換します。字幕や追加の音声トラックは含まれません。
- **コーデック：** デコード・エンコードできるコーデックはブラウザとデバイスによって異なります。変換できないトラックがある場合は、音や映像のないファイルを作らず、メッセージを表示して止まります。
- **メモリ：** 変換後の動画はダウンロードするまでメモリに保持されるため、スマートフォンでは非常に大きなファイルの変換に失敗することがあります。

## プライバシー

動画はお使いのデバイス上でのみ処理されます。このページは動画をアップロードも保存もせず、Cookie も使いません。
