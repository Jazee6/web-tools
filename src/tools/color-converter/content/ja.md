  - q: 透明度はどう扱われますか？
    a: アルファはすべての結果に引き継がれます。HEX には桁が 2 つ増え（#ff573380）、ほかの形式にはスラッシュと数値が付きます（rgb(255 87 51 / 0.5)）。アルファは小数第 3 位に丸められ、完全に不透明な色にはアルファを付けません。
  - q: 変換後の値が入力と少し違うのはなぜですか？
    a: RGB と HEX の各チャンネルは 0〜255 の整数なので、HSL、HWB、OKLCH で入力した色は、まず最も近い 8 ビットの値に丸められます。ほかの形式はその丸めた色から計算されるため、5 つの結果は互いに食い違いません。HSL と HWB の値は小数第 1 位まで、OKLCH の明度と彩度は小数第 4 位まで表示されます。

## このカラーツールでできること

入力を sRGB 色空間の色に変換し、5 つの CSS 形式で書き出します。HSL と HWB は [CSS Color Module Level 4](https://www.w3.org/TR/css-color-4/) の式で RGB から計算します。OKLCH は [Oklab](https://bottosson.github.io/posts/oklab/) の極座標表現で、sRGB と Oklab の変換には Björn Ottosson が公開している行列を使います。結果は、`rgb(255 87 51)`、`hsl(10.6 100% 60%)`、`oklch(0.6804 0.21 33.7)` のような、現在の CSS のスペース区切りの書き方です。

## オプションと制限

- **入力：** 一度に 1 色です。前後の空白は無視され、関数名と 16 進数の大文字・小文字は区別されません。
- **対応形式：** 3、4、6、8 桁の 16 進数、`rgb()`、`rgba()`、`hsl()`、`hsla()`、`hwb()`、`oklch()`。色名、`color()`、`lab()`、`lch()`、`oklab()`、`var()` には対応していません。
- **範囲外の値：** RGB の各チャンネル、彩度、明度、白、黒、アルファは有効な範囲に切り詰められます。色相は循環するので、`hsl(-120 100% 50%)` は `hsl(240 100% 50%)` と同じ青です。
- **精度：** HEX と RGB は 8 ビットです。色相、彩度、明度、白、黒は小数第 1 位まで、OKLCH の明度と彩度は小数第 4 位まで表示します。
- **グレー：** 色相のない色は、色相 0 で表示します。

## プライバシー

処理はお使いのデバイス上でのみ行われます。ページは入力内容をアップロードも保存もせず、Cookie も使いません。
