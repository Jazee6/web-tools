## 剪切原理

本工具用开源媒体库 Mediabunny 读取视频。使用"快速"时，它直接复制你所选部分的现有视频和音频数据；使用"精确"时，它先解码该部分，再用浏览器内置的 WebCodecs API 重新编码，通常还能用上硬件加速。处理在后台线程中进行，页面不会卡顿。

## 选项与限制

- **输入：** MP4、MOV、WebM 和 MKV 文件，不超过 500 MB。片段保持相同的格式。
- **剪掉的内容：** "快速"剪出的片段可能保留你设定的时间之外紧邻的帧，即使播放器不显示它们；"精确"则一帧都不会留下。
- **轨道：** 保留主视频轨和主音频轨；字幕和额外的音轨会被丢弃。
- **编码格式：** 使用"精确"时，能解码和编码哪些格式取决于你的浏览器和设备。例如 Firefox 没有 AAC 编码器，因此在 Firefox 中 MP4 和 MOV 会使用 Opus 音频。如果某条轨道无法处理，工具会停止并给出提示，而不会生成没有声音或画面的文件。
- **内存：** 剪切后的视频在下载前保存在内存中，在手机上处理很大的文件可能失败。

## 隐私

你的视频只在你的设备上处理。页面不会上传或保存视频，也不使用 Cookie。
