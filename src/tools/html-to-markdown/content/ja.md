faq:
  - q: HTML コードではなくリッチテキストを貼り付けられますか？
    a: はい。Web ページ、Word、Google ドキュメント、メールからコピーすると、クリップボードには書式の元になる HTML も入ります。「HTML」欄に貼り付けるとプレーンテキストではなくその HTML が挿入されるため、見出し、リンク、リスト、表が残ります。クリップボードにプレーンテキストしかない場合は、通常どおり貼り付けられます。
  - q: 表はどのように変換されますか？
    a: セルのある表はすべて Markdown テーブルになり、1 行目は通常のセルでもヘッダー行になります（Word や Google ドキュメントからコピーした表はこの形です）。セル内の | は \| にエスケープされ、1 つのセル内の複数の段落や改行は <br> でつながれます。複数列にまたがるセルの後には空のセルが補われます。ヘッダーセルに設定された左揃え、中央揃え、右揃えは保たれます。
  - q: 何が削除されますか？
    a: <script>、<style>、<noscript>、<iframe>、<template> と、タイトルを含むページの <head> です。それ以外はナビゲーションメニューやフッターも含めてすべて変換されるため、ページの必要な部分だけを貼り付けてください。
  - q: どの Markdown スタイルで出力されますか？
    a: GitHub Flavored Markdown です。# の見出し、- の箇条書き、*斜体*、**太字**、``` のフェンス付きコードブロック（code 要素に language-js などの class があれば言語名付き）、インラインリンク、~~取り消し線~~、チェックボックスから作る - [x] のタスクリスト項目を使います。スタイルは固定なので、出力は毎回同じ形になります。
  - q: 一部の HTML 要素が跡形もなく消えるのはなぜですか？
    a: Markdown には色、フォント、フォーム、レイアウトを表す構文がないため、テキストだけが残ります。画像はアドレスと代替テキストを保ちますが、パソコン上のファイルを指すアドレスはほかの場所では機能しません。

## HTML Markdown 変換の仕組み

ブラウザ自身の HTML パーサーで HTML を読み込み、[Turndown](https://github.com/mixmark-io/turndown) で Markdown に変換します。そのため、乱れた HTML や不完全な HTML も、ブラウザが表示するときと同じように読み取られます。表、取り消し線、タスクリストの GitHub Flavored Markdown のルールはこのサイト独自のもので、ヘッダーセルのない表も HTML のまま残さずに変換します。

## オプションと制限

- **入力：** HTML フラグメントまたはページ全体、最大 1,000,000 文字。
- **貼り付け：** クリップボードにリッチテキストの HTML があれば HTML を貼り付け、プレーンテキストはそのまま貼り付けます。
- **削除されるもの：** スクリプト、スタイル、noscript、iframe、template、ページの head。ナビゲーション、ヘッダー、フッターはほかの内容と同様に変換されます。
- **表：** 1 行目は常にヘッダー行です。複数行にまたがるセルは繰り返されず、セル内の表はそのセル内のテキストになります。
- **リスト：** HTML のリスト（<ul> と <ol>）は Markdown のリストになります。Word でよくあるように、記号や番号で始まる段落として届いたリストは段落のままです。
- **非対応：** * の箇条書き、Setext 見出し、参照形式のリンクなど、別の Markdown スタイルの選択。

## プライバシー

処理はお使いのデバイス上でのみ行われます。ページは HTML をアップロードも保存もせず、Cookie も使いません。
