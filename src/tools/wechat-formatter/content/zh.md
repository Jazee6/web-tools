## 公众号排版是怎么工作的

公众号编辑器会去掉粘贴内容里的样式表和 class 名称，所以文章的全部格式都写成了内联样式。排版工具用 [marked](https://marked.js.org/) 读取你的 Markdown，并按本站的排版样式写出每个标题、段落、列表、表格、引用和代码块：16 px 字号、1.75 倍行高、中性配色和系统字体（编辑器无法加载网络字体）。代码块用 [Shiki](https://shiki.style/) 按 GitHub Light 配色高亮。

## 选项与限制

- **Markdown：**CommonMark 加上 GitHub 的表格、任务列表和删除线，最多 200,000 个字符。任务列表项显示为 ☑ 或 ☐，因为编辑器会去掉复选框。
- **强调色：**中性、蓝色、绿色、橙色、红色、玫红、紫色或黄色。它用于二级标题旁的竖条、引用的边框、行内代码、公众号文章链接和参考链接的编号；正文保持接近黑色。
- **链接：**指向 mp.weixin.qq.com 的链接仍可点击；其他 http 和 https 链接会变成文末带编号的参考链接。其他类型的链接只保留文字。
- **图片：**只支持 http 和 https 地址；其他地址只保留替代文字。
- **复制：**两个按钮都使用浏览器的剪贴板，有些浏览器需要你授予权限；"复制富文本"还要求浏览器能复制带格式的 HTML。复制失败时，请允许访问剪贴板后重试。
- **不支持：**原始 HTML（会显示为文字）、数学公式和图表。

## 隐私

你的文章只在你的设备上处理。页面不会上传它、不会把它保存在服务器上，也不使用 Cookie。
