## WeChat 公式アカウント記事フォーマッターの仕組み

WeChat 公式アカウントのエディターは、貼り付けた内容からスタイルシートとクラス名を取り除きます。そのため、記事の書式はすべてインラインスタイルとして書き出します。フォーマッターは [marked](https://marked.js.org/) で Markdown を読み込み、見出し、段落、リスト、表、引用、コードブロックを当サイトのタイポグラフィのスタイルで書き出します。文字サイズは 16 px、行の高さは 1.75、配色はニュートラルで、エディターが Web フォントを読み込めないためシステムフォントを使います。コードブロックは [Shiki](https://shiki.style/) により GitHub Light の配色でハイライトされます。

## オプションと制限

- **Markdown：** CommonMark に GitHub の表、タスクリスト、取り消し線を加えたもので、最大 200,000 文字です。エディターがチェックボックスを取り除くため、タスクリストの項目は ☑ または ☐ で表示されます。
- **アクセントカラー：** ニュートラル、ブルー、グリーン、オレンジ、レッド、ローズ、バイオレット、イエローから選べます。見出し 2 の横の縦線、引用の枠線、インラインコード、WeChat のリンク、参考リンクの番号に色が付き、本文はほぼ黒のままです。
- **リンク：** mp.weixin.qq.com へのリンクはクリックできるまま残り、その他の http と https のリンクは記事末尾の番号付き参考リンクになります。それ以外のリンクは文字だけが残ります。
- **画像：** http と https のアドレスのみ対応しています。それ以外は代替テキストだけが残ります。
- **コピー：** どちらのボタンもブラウザのクリップボードを使います。ブラウザによっては許可が必要です。「リッチテキストをコピー」には、書式付きの HTML をコピーできるブラウザも必要です。コピーに失敗した場合は、クリップボードへのアクセスを許可して、もう一度お試しください。
- **非対応：** 生の HTML（文字として表示）、数式、図。

## プライバシー

記事はお使いのデバイス上でのみ処理されます。ページは記事をアップロードせず、サーバーに保存せず、Cookie も使いません。
