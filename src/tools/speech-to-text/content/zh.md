## 转录原理

本工具用 Mediabunny 和 WebCodecs API 解码音频，转换成 16 kHz 单声道后交给 OpenAI 开源的语音识别模型 Whisper base。模型通过 ONNX Runtime 在后台线程中运行。如果你的设备有性能足够的 GPU，模型的一部分会用 WebGPU 在 GPU 上运行，速度更快；否则全部用 WebAssembly 在 CPU 上运行。较长的录音会被切成相互重叠的 30 秒片段，识别后再拼接起来。

## 限制

- **输入：** MP3、M4A、AAC、WAV、OGG、Opus、FLAC 和 WebM 音频，或 MP4、MOV、WebM、MKV 视频中的音轨，文件不超过 1 GB，时长不超过 60 分钟。
- **速度：** 在较新的笔记本电脑上，1 分钟的音频用 WebGPU 只需几秒钟，不用 WebGPU 时最多约 20 秒。
- **下载：** 模型约 105–125 MB，首次使用时下载。
- **准确度：** Whisper base 是小型模型，背景噪声、音乐和多人同时说话都会降低识别质量。
- **中文：** Whisper 经常用繁体字输出中文，普通话录音也一样。

## 隐私

你的录音只在你的设备上处理。页面不会上传或保存它，也不使用 Cookie。
