## 文字起こしのしくみ

このツールは Mediabunny と WebCodecs API で音声をデコードし、16 kHz モノラルに変換してから、OpenAI がオープンソースで公開している音声認識モデル Whisper base に渡します。モデルは ONNX Runtime によりバックグラウンドのスレッドで動きます。十分な性能の GPU があれば、モデルの一部を WebGPU で GPU 上で実行するため高速です。ない場合はすべて WebAssembly で CPU 上で実行します。長い録音は 30 秒ずつ重なり合う区間に分けて認識し、最後につなぎ合わせます。

## 制限

- **入力：** MP3、M4A、AAC、WAV、OGG、Opus、FLAC、WebM の音声、または MP4、MOV、WebM、MKV 動画の音声トラック。1 GB 以下、60 分以内。
- **速度：** 最近のノートパソコンでは、1 分の音声に WebGPU ありで数秒、なしで最大 20 秒ほどかかります。
- **ダウンロード：** モデルは約 105〜125 MB で、初回使用時にダウンロードされます。
- **精度：** Whisper base は小型のモデルです。背景の雑音、音楽、複数人の同時発話があると品質が下がります。
- **中国語：** Whisper は中国語を繁体字で出力することがよくあります（中国本土の標準中国語でも同様です）。

## プライバシー

録音はお使いのデバイス上でのみ処理されます。このページはファイルをアップロードも保存もせず、Cookie も使いません。
