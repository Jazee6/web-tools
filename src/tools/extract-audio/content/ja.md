  - q: MP4 の動画を MP3 に変換するには？
    a: MP4 ファイルを選び、音声形式を MP3 のままにして「音声を抽出」を押します。音声は 192 kbps の MP3 にエンコードされ、映像は含まれません。MOV、WebM、MKV の動画でも同じです。

    a: どの機器でも再生できるファイルが欲しいだけなら MP3 です。M4A（AAC）は同じサイズでやや音質が良く、iPhone や Mac に向いています。WAV は非圧縮でサイズがかなり大きく、音声編集ソフト向きです。「元の音声トラック」が最も速く、音質も一切落ちません。

  - q: 抽出すると音質は下がりますか？

  - q: 動画に音声トラックが複数ある場合は？
    a: 抽出されるのはメインの音声トラックだけです。別の言語の吹き替えや解説など、ほかのトラックは含まれません。

## 抽出の仕組み

このツールはオープンソースのメディアライブラリ Mediabunny で動画を読み込み、メインの音声トラックだけを残します。WAV と M4A では、ブラウザに組み込まれた WebCodecs API で音声をデコードしてエンコードします。ブラウザは MP3 をエンコードできないため、MP3 では、オープンソースの MP3 エンコーダー LAME をもとにしたエンコーダーを、初めて必要になったときに読み込みます。「元の音声トラック」では何もデコードせず、音声データをそのままコピーします。処理はバックグラウンドのスレッドで行われるため、ページの操作は止まりません。

## オプションと制限

- **入力：** 500 MB までの MP4、MOV、WebM、MKV ファイル。
- **MP3：** 192 kbps、最大 2 チャンネル。サラウンド音声はステレオにまとめられ、一般的でないサンプリングレートは 48 kHz に変換されます。
- **M4A：** 192 kbps の AAC。Firefox には AAC エンコーダーがないため、Firefox では動画の音声がもともと AAC の場合にだけ M4A を使え、その場合はコピーされます。
- **WAV：** 16 ビットの非圧縮音声で、ステレオなら 1 分あたり約 10 MB です。
- **元の音声トラック：** AAC は M4A、MP3 は MP3、Opus と Vorbis は OGG、FLAC は FLAC、PCM は WAV に入ります。AC-3 や DTS などのほかのコーデックは MKA（Matroska 音声）ファイルになります。
- **トラック：** 抽出されるのはメインの音声トラックだけです。動画に音声がない場合は、空のファイルを作らずにメッセージを表示します。
- **メモリ：** 音声ファイルはダウンロードするまでメモリ上に保持されます。長い動画を WAV で抽出するとファイルが非常に大きくなり、スマートフォンでは失敗することがあります。

## プライバシー

動画はお使いのデバイス上でのみ処理されます。このページは動画をアップロードも保存もせず、Cookie も使いません。
