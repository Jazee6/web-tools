## 背景削除の仕組み

ブラウザ内蔵の画像デコーダー（HEIC は libheif の WebAssembly 版）で画像をデコードし、そのコピーをオープンソースのセグメンテーションモデル BiRefNet_lite（MIT ライセンス）に渡します。モデルはバックグラウンドのスレッドで ONNX Runtime により実行され、ピクセルごとに被写体に属する確からしさを出力します。このマスクを元の画像サイズに拡大して透明度として使います。被写体は残り、背景は透明になるか、入力した色で塗りつぶされます。結果は PNG（さらに OxiPNG で最適化）、WebP、JPEG のいずれかでエンコードされます。

## オプションと制限

- **入力：** 50 MB までの HEIC、JPEG、PNG、WebP、AVIF 画像 1 枚。もともと透明な部分は、背景色を入力しない限り透明のままです。
- **出力：** PNG と WebP は透明背景を保ちます。JPEG は透明に対応していないため、背景色が必要です。画像の幅と高さは変わりません。
- **背景色：** #ffffff や #fff のような 16 進数。空欄なら背景は透明です。
- **品質：** WebP と JPEG に適用され、初期値は 90 です。PNG は常に可逆です。
- **ブラウザ：** WebGPU があり、GPU が 16 ビット浮動小数点に対応していれば、モデルは GPU 上で動き、画像を 1024 × 1024 ピクセルで解析します。そうでない場合は CPU 上で 512 × 512 ピクセルで動くため、大きな画像では輪郭の精度が下がることがあります。ブラウザが許可する場合、CPU での処理は複数のスレッドを使います。
- **ダウンロード：** モデルとその実行環境は WebGPU ありで約 150 MB、なしで約 125 MB で、初回使用時にダウンロードされます。
- **精度：** モデルは主な被写体を自動で見つけます。残す物体を指定することはできません。

## プライバシー

画像はお使いのデバイス上でのみ処理されます。このページは画像をアップロードも保存もせず、Cookie も使いません。
