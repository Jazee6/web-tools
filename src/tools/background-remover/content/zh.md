## 背景去除原理

工具用浏览器内置的图片解码器解码图片（HEIC 用 libheif 的 WebAssembly 版本），再把一份副本交给开源的分割模型 BiRefNet_lite（MIT 许可证）。模型在后台线程中由 ONNX Runtime 运行，为每个像素算出它属于主体的可能性。这张遮罩会放大回图片的原始尺寸，作为图片的透明度：主体保留，背景变成透明，或填充为你填写的颜色。结果编码为 PNG（再用 OxiPNG 优化）、WebP 或 JPEG。

## 选项与限制

- **输入：**一张 HEIC、JPEG、PNG、WebP 或 AVIF 图片，不超过 50 MB。原本透明的区域会保持透明，除非你填写了背景色。
- **输出：**PNG 和 WebP 保留透明背景；JPEG 不支持透明，需要填写背景色。图片的宽高不变。
- **背景色：**十六进制代码，例如 #ffffff 或 #fff。留空则背景透明。
- **质量：**用于 WebP 和 JPEG，默认 90。PNG 始终无损。
- **浏览器：**有 WebGPU 且 GPU 支持 16 位浮点数时，模型在 GPU 上运行，按 1024 × 1024 像素分析图片。否则在 CPU 上按 512 × 512 像素运行，大图的边缘可能不够精细。浏览器允许时，CPU 路径会使用多个线程。
- **下载：**模型及其运行时在有 WebGPU 时约 150 MB，没有时约 125 MB，首次使用时下载。
- **准确度：**模型自动识别主要主体，无法指定保留哪个物体。

你的图片只在你的设备上处理。页面不会上传、不会保存图片，也不使用 Cookie。
