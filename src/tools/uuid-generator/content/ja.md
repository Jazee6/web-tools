## UUID の生成方法

各識別子はプラットフォームの Web Crypto `crypto.randomUUID()` API から取得します。結果は `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx` 形式の UUID v4 で、小文字の場合の `y` は 8、9、a、b のいずれかです。ボタンを押すたびに新しい一組を生成します。テキストやシードの入力はありません。

## オプションと制限

- **個数**：1 から 1,000 までの整数で、初期値は 1 です。
- **大文字と小文字**：初期設定は小文字です。大文字でもハイフン付きの形式は変わりません。
- **非対応**：v4 以外の UUID バージョン、独自のシード、波かっこ、URN 接頭辞。

## プライバシー

生成はお使いのデバイス上でのみ行われます。ページは生成した UUID をアップロードも保存もせず、Cookie も使いません。
