## ファイルはデバイスに留まります

ファイルを扱うツールはブラウザー内で動作し、ファイルを当サイトのサーバーへアップロードしません。処理に必要なコードや、一部のツールで使うモデルはダウンロードします。

## サーバーに接続する機能

- **HTTP ヘッダーチェッカー**は、入力した URL を当サイトのサーバーに送り、接続先のレスポンスヘッダーを確認します。`#` 以降は削除されますが、パスとクエリは送信されます。秘密情報を含む URL は入力しないでください。不正利用を防ぐ Cloudflare Turnstile には、認証トークンと IP アドレスが送られます。[Turnstile のプライバシーポリシー](https://www.cloudflare.com/turnstile-privacy-policy/)をご覧ください。
- **DNS ルックアップ**は、選択した Cloudflare または Google の DNS サービスに、ドメインとレコードの種類を直接送信します。当サイトのサーバーは経由せず、既定では Cloudflare を使います。サービス提供者には IP アドレスも伝わります。[Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)と [Google Public DNS のプライバシー情報](https://developers.google.com/speed/public-dns/privacy)をご覧ください。
- **リモート MCP**は、ツール名と引数を当サイトのサーバーに送り、そこで実行します。通常ブラウザーで動くツールでも同じです。機密情報は送信しないでください。

## 匿名の利用統計

ツールの利用状況やエラーを把握するため、訪問者識別子を使わず、限られた統計を収集します。

| 報告対象         | 含まれる情報                                                                 |
| ---------------- | ---------------------------------------------------------------------------- |
| ツールの利用     | ツール名、表示言語、結果の種類、処理時間の範囲                               |
| 予期しないエラー | エラーの種類と発生元、分かる場合はツール名、表示言語、ブラウザーで使える機能 |
| 含まれない情報   | 入力、出力、ファイル、IP アドレス、エラーメッセージ、詳細なエラー追跡情報    |

ツールの実行が終わるたびに、10% の確率で報告します。訪問者の 10% を選ぶ仕組みではありません。予期しないエラーは抽出せずに報告しますが、重複は抑え、1 セッションにつき異なるエラーを最大 20 件まで報告します。届かない場合もあり、再送はしません。

## Cloudflare Web Analytics

Cloudflare Web Analytics は Cookie を使わず、ページの閲覧数と読み込み性能を測定します。Cloudflare が測定スクリプトを自動で追加でき、上記のツール利用統計とは別の仕組みです。データの扱いは [Cloudflare のプライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご覧ください。

## サーバーログと IP アドレス

当サイトのサーバーは、不正利用を防ぐために IP アドレスでリクエスト数を制限しますが、利用統計には IP アドレスを記録しません。Cloudflare はサイトの配信やリクエストの確認時に、IP アドレスなどの接続データを扱います。

サーバーログにはツール、処理時間、結果が記録されます。予期しないサーバーエラーでは、エラーメッセージや詳細なエラー追跡情報が含まれる場合もあります。Cloudflare によるデータの扱いと保存については、同社の[プライバシーポリシー](https://www.cloudflare.com/privacypolicy/)をご覧ください。

## ブラウザーに保存するもの

ブラウザーは、お気に入り、最近使ったツールを最大 20 件、選択項目・スイッチ・数値などのフォーム設定を保存します。ファイルや自由入力のテキストはフォーム設定として保存せず、プリセットの選択内容も保存対象外です。

訪問したページと必要なリソースはオフライン用にキャッシュし、ダウンロードしたモデルは別にキャッシュします。同じセッションでエラーを重複報告しないための情報も一時的に保存します。

フッターの**ローカルデータを消去**で、設定、お気に入り、最近の利用履歴、オフラインとモデルのキャッシュ、一時的なローカルファイルを削除し、オフライン機能を停止してページを再読み込みします。ブラウザーの制限により、一部の一時ファイルを削除できない場合があります。通常のウェブキャッシュ、Cookie、セッション内のエラー重複防止の印、サーバーの記録は消去しません。再読み込み後に再びキャッシュが始まることがあります。
