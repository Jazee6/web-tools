## 文件留在你的设备上

文件型工具在浏览器里处理文件，不会把文件上传到我们的服务器。浏览器仍需下载处理所用的代码，部分工具还需下载模型。

## 会连接服务器的功能

- **HTTP 响应头检查器**会把你输入的网址发给我们的服务器，以检查目标网站的响应头。`#` 后的部分会被移除，但路径和查询参数会发送，请避免输入含有秘密信息的网址。Cloudflare Turnstile 用于防滥用，会接收验证令牌和你的 IP 地址。详见 [Turnstile 隐私政策](https://www.cloudflare.com/turnstile-privacy-policy/)。
- **DNS 查询**会把域名和记录类型直接发给你选择的 Cloudflare 或 Google DNS 服务，不经过我们的服务器，默认使用 Cloudflare。服务商也会看到你的 IP 地址。详见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)和 [Google Public DNS 隐私说明](https://developers.google.com/speed/public-dns/privacy)。
- **远程 MCP**会把工具名称和调用参数发给我们的服务器，并在服务器上执行工具，即使同一工具平时在浏览器里运行也是如此。请勿发送敏感信息。

## 匿名使用统计

我们收集有限的统计信息来了解工具使用情况和错误，不使用访客标识。

| 上报内容 | 包含的信息                                                     |
| -------- | -------------------------------------------------------------- |
| 工具使用 | 工具名称、界面语言、结果类别和耗时区间                         |
| 意外错误 | 错误类型和来源、涉及的工具（如已知）、界面语言及浏览器可用功能 |
| 不包含   | 你的输入、输出、文件、IP 地址、错误消息或详细错误追踪信息      |

每次工具运行结束后有 10% 的概率上报，并非选取 10% 的访客。意外错误不抽样；重复错误会被抑制，每个会话最多上报 20 种不同错误。上报可能丢失，不会重试。

## Cloudflare Web Analytics

Cloudflare Web Analytics 不用 Cookie 来统计页面访问和加载性能。Cloudflare 可自动加入统计脚本，它与上面的工具使用统计相互独立。其数据处理方式请见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

## 服务器日志和 IP 地址

为防滥用，我们的服务器会用你的 IP 地址限制请求，但不会把 IP 写进使用统计。Cloudflare 在提供网站和检查请求时会处理连接数据，包括 IP 地址。

服务器日志记录工具、耗时和结果。意外的服务器错误还可能包含错误消息和详细错误追踪信息。Cloudflare 对这些数据的处理和保留方式请见其[隐私政策](https://www.cloudflare.com/privacypolicy/)。

## 浏览器里保存的东西

浏览器会保存收藏、最多 20 个最近使用的工具，以及下拉选项、开关和数字等表单偏好。文件和自由文本不会作为表单偏好保存，预设选项也不会保存为偏好。

访问过的页面和所需资源会缓存下来供离线使用，下载的模型单独缓存。浏览器还会临时记录信息，以免在同一会话中重复上报错误。

页脚的**清除本地数据**会删除偏好、收藏、最近使用记录、离线缓存、模型缓存和临时本地文件，停用离线服务后重新加载页面。浏览器限制可能导致部分临时文件无法删除。它不会清除浏览器常规网页缓存、Cookie、会话中的错误去重标记或服务器记录。重新加载后可能再次开始缓存。
