## 在浏览器里处理日常任务

Web Tools 提供文档、图片、音视频和文本工具。选择工具、添加输入，再复制或下载结果。

## 工具怎么工作

文件在你的设备上处理，不会上传到我们的服务器。工具使用浏览器自带的功能和下载的处理库；速度和支持的格式取决于浏览器和可用内存。

部分功能需要联网：HTTP 响应头检查器使用我们的服务器，DNS 查询会连接你选择的 DNS 服务商，远程 MCP 调用也在我们的服务器上执行。各工具页面会说明选项和限制。

## 内容怎么写

代码和页面内容由 agent 撰写。发布流程使用模型审核：先对照实现核对英文内容，再以英文为依据审核各语言译文。等待审核的页面不会进入搜索索引。

说明尽量先给答案，再讲实际限制。如果发现错误或有不清楚的地方，请到 GitHub 反馈。公开 issue 中不要包含私人文件、密码或其他敏感信息。
