## Alltagsaufgaben im Browser

Web Tools bietet Tools für Dokumente, Bilder, Audio, Video und Text. Wählen Sie ein Tool, geben Sie Ihre Daten ein und kopieren oder laden Sie das Ergebnis herunter.

## So funktionieren die Tools

Dateien werden auf Ihrem Gerät verarbeitet und nicht auf unseren Server hochgeladen. Die Tools nutzen Browserfunktionen und heruntergeladene Verarbeitungsbibliotheken. Geschwindigkeit und unterstützte Formate hängen vom Browser und dem verfügbaren Arbeitsspeicher ab.

Einige Funktionen brauchen eine Verbindung: Der HTTP-Header-Checker nutzt unseren Server, die DNS-Abfrage kontaktiert Ihren gewählten DNS-Anbieter und entfernte MCP-Aufrufe werden auf unserem Server ausgeführt. Die Tool-Seiten erklären Optionen und Grenzen.

## So entstehen die Inhalte

Agenten schreiben den Code und die Seiteninhalte. Unser Veröffentlichungsprozess nutzt Modellprüfungen: Englische Inhalte werden mit der Implementierung abgeglichen, danach jede Übersetzung mit dem Englischen. Seiten, deren Prüfung noch aussteht, werden nicht in Suchindizes aufgenommen.

Die Beschreibungen sollen zuerst die Antwort geben und praktische Grenzen erklären. Melden Sie Fehler oder Unklarheiten gern auf GitHub. Fügen Sie einem öffentlichen Issue keine privaten Dateien, Passwörter oder sonstigen sensiblen Daten bei.
