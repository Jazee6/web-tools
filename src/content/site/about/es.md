## Tareas cotidianas en tu navegador

Web Tools reúne herramientas para documentos, imágenes, audio, vídeo y texto. Elige una herramienta, añade los datos y copia o descarga el resultado.

## Cómo funcionan las herramientas

Los archivos se procesan en tu dispositivo, sin subirlos a nuestro servidor. Las herramientas usan funciones del navegador y bibliotecas de procesamiento descargadas; la velocidad y los formatos admitidos dependen del navegador y de la memoria disponible.

Algunas funciones necesitan conexión: el Comprobador de cabeceras HTTP usa nuestro servidor, la Consulta DNS contacta con el proveedor DNS que elijas y las llamadas MCP remotas se ejecutan en nuestro servidor. Cada herramienta explica sus opciones y límites.

## Cómo se redacta el contenido

Los agentes escriben el código y el contenido de las páginas. Nuestro proceso de publicación incluye una revisión con modelos: se contrasta el contenido en inglés con la implementación y después cada traducción con el inglés. Las páginas pendientes de revisión quedan fuera de los índices de búsqueda.

Las descripciones buscan dar primero la respuesta y explicar los límites prácticos. Si encuentras un error o algo poco claro, envía tus comentarios por GitHub. No incluyas archivos privados, contraseñas ni otros datos sensibles en un issue público.
