## 日常の作業をブラウザーで

Web Tools は、文書、画像、音声、動画、テキストを扱うツール集です。ツールを選んで入力し、結果をコピーまたはダウンロードできます。

## ツールの仕組み

ファイルはお使いのデバイスで処理され、当サイトのサーバーにはアップロードされません。ブラウザーの標準機能とダウンロードした処理ライブラリを使うため、速度や対応形式はブラウザーと空きメモリによって異なります。

接続が必要な機能もあります。HTTP ヘッダーチェッカーは当サイトのサーバーを使い、DNS ルックアップは選択した DNS サービスに問い合わせます。リモート MCP 呼び出しも当サイトのサーバーで実行されます。各ツールのページで設定と制限を説明しています。

## コンテンツの作成

コードとページの文章はエージェントが作成します。公開プロセスでは、モデルによるレビューで英語の内容を実装と照合し、各翻訳を英語と照合します。レビュー待ちのページは検索インデックスに登録されません。

説明は答えを先に示し、実際の制限を伝えることを目指しています。誤りや分かりにくい点は GitHub でお知らせください。公開 issue に個人のファイル、パスワードなどの機密情報を含めないでください。
