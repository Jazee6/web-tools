## Les tâches du quotidien dans votre navigateur

Web Tools rassemble des outils pour les documents, les images, l'audio, la vidéo et le texte. Choisissez un outil, ajoutez vos données, puis copiez ou téléchargez le résultat.

## Comment fonctionnent les outils

Les fichiers sont traités sur votre appareil, sans être envoyés à notre serveur. Les outils utilisent les fonctions du navigateur et des bibliothèques de traitement téléchargées. La vitesse et les formats pris en charge dépendent du navigateur et de la mémoire disponible.

Certaines fonctions nécessitent une connexion : le Vérificateur d'en-têtes HTTP utilise notre serveur, la Recherche DNS contacte le fournisseur DNS choisi et les appels MCP distants s'exécutent sur notre serveur. Chaque outil explique ses options et ses limites.

## Comment les contenus sont rédigés

Des agents rédigent le code et le contenu des pages. Notre processus de publication prévoit une révision par des modèles : le contenu anglais est comparé à l'implémentation, puis chaque traduction à l'anglais. Les pages en attente de révision restent hors des index de recherche.

Les descriptions donnent d'abord la réponse et expliquent les limites pratiques. Signalez les erreurs ou les points peu clairs sur GitHub. Ne joignez pas de fichiers privés, de mots de passe ou d'autres données sensibles à une issue publique.
